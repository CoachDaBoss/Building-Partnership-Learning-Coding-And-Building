# Production Roadmap

## Phase 1 — Current MVP
Private gate, roles, studio recording, beat library, safe plugin presets, release rights ledger, live mesh sessions, group chat, EPK, owner admin and audit log.

## Phase 2 — Pro Studio
Multitrack timeline, waveform editor, clip trim/split, punch recording, metronome/count-in, MIDI, sample library, stem bounce, project revisions, autosave and mastering chains.

## Phase 3 — Private Infrastructure
PostgreSQL, Redis, MinIO/S3, job workers, FFmpeg transcodes, backups, signed URLs, antivirus scanning, email verification, MFA/passkeys, rate limiting and reverse-proxy HTTPS.

## Phase 4 — Scalable Live Sessions
Self-host LiveKit (or another SFU) plus coturn. Add lobby, ringing state, host/cohost controls, permissions, room recording consent, session recordings, chat/file retention and moderation.

## Phase 5 — Rights + Royalties Operations
Split-sheet acceptance flow, agreement uploads, immutable revisions, ISRC/UPC metadata, royalty-import connectors, statements, payment-provider integration and tax-document workflows reviewed by counsel/accounting professionals.

## Phase 6 — Distribution + Social
Canonical release pages, approved social OAuth integrations, distributor/API integrations where contracts permit, scheduled release campaigns and analytics.

## Phase 7 — Desktop / Mobile
Signed desktop companion for local VST3/AU hosting, low-latency audio I/O and offline projects. Mobile apps can use the same API. Android APK/iOS packaging is separate from the artist EPK feature.
